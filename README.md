# dashboard-boo

Administrative Dashboard for **BOO Automotive & Spare Parts Platform** built with React, Vite, React Router, Lucide Icons, and Axios.

## Features
- **Product & Inventory Management**: Add, edit, manage stock, categories, and OEM specifications.
- **Vehicle Showroom Management**: Add new/imported cars, update prices, specs, and status.
- **Orders & Inquiries Pipeline**: Monitor customer orders, update statuses, and review messages.
- **Maintenance Booking Center**: Manage service appointments and technician assignments.
- **Content & Hero Slider Management**: Dynamic CMS for marketing banners and company info.

## Getting Started

### 1. Installation
```bash
npm install
```

### 2. Run Development Server
```bash
npm run dev
```

### 3. Production Build
```bash
npm run build
```
